# Pomodoro Clock

## Descripción

Elegimos "Pomodoro Clock" (Tier 1 de App Ideas) porque resuelve la necesidad
de gestionar el tiempo de estudio o trabajo mediante intervalos enfocados,
sin depender de una app comercial con anuncios o suscripción. Su alcance
—temporizador de trabajo/descanso con controles de inicio, pausa, detención
y reinicio— es alcanzable por un equipo principiante en el tiempo
disponible de esta práctica.

## User Stories

- Como usuario, quiero ver un temporizador de 25 minutos para la sesión de
  trabajo, para saber cuánto me falta de concentración.
- Como usuario, quiero que al terminar la sesión de trabajo aparezca
  automáticamente un temporizador de 5 minutos de descanso, para tomar una
  pausa.
- Como usuario, quiero poder iniciar y pausar el temporizador, para
  controlar cuándo corre el tiempo.
- Como usuario, quiero poder detener y reiniciar el temporizador, para
  empezar de nuevo si me equivoco.
- Como usuario, quiero escuchar un sonido cuando el temporizador llega a
  00:00, para notarlo aunque no esté mirando la pantalla.
- (adaptadas del banco de proyectos elegido)

## Metodología

Ágil ligero (Kanban con tres columnas: To do / In progress / Done) — se
eligió este enfoque porque el equipo puede ajustar el alcance sobre la
marcha, mostrar avance visible en cada sesión de clase, y GitHub Projects
está diseñado exactamente para este tipo de seguimiento visual.

## Cómo ejecutar el proyecto

No requiere instalación ni dependencias. Basta con abrir `index.html` en
cualquier navegador, o usar la extensión "Live Server" de VS Code para
recarga automática mientras se edita.
